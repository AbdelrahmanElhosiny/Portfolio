## Reconsider before executing

- **The domain must be picked now.** It replaces the `yourname.dev` placeholder in the seed, `.env.example` and the Ingress. The cheapest registrar is the default; it costs about $12–16/yr and credits probably don't cover it.
- **How images reach the server before CI (stage 6).** Proposed: he pushes arm64 images to GHCR from the Mac with `docker buildx --push`, using a GitHub token with only `write:packages`, and revokes it once stage 6 runs. A stated, temporary exception to "no long-lived keys". Alternative: `k3s ctr images import` via S3.
- **Real client IP.** k3s ServiceLB DNATs traffic, which hides the visitor's IP unless the Traefik Service uses `externalTrafficPolicy: Local`. Traefik then sets `X-Forwarded-For`, and the API trusts only the pod CIDR `10.42.0.0/16` (the k3s default; confirm from the node's `spec.podCIDR`).
- **HSTS and preload.** Start with `max-age=300`, raise it to 2 years once HTTPS is stable, and decide on `preload` separately (it is hard to undo).
- **Let's Encrypt rate limits.** Use the staging issuer first, and switch to prod only once staging issues.
- **Memory.** cert-manager adds three pods. Re-check `kubectl top` against the §3 budget before stage 7 adds Flux.
- **`prevent_destroy`** on the data volume turns on now.
- **Check at execution:** current k3s and cert-manager versions (pin both); Route 53 zone price ($0.50).
